# TIME 构建实现

规约：[S05-construction.md](../../../docs/specs/S05-construction.md)。

## 模块地图

- time_pipeline / scene_pipeline / event_pipeline：各层确定性分组和参数校验。
- grouping_support：语义表示、向量合法性与相邻相似度计算。
- parent_enrichment：结构摘录、完整事实汇集、模型摘要及父层标注。
- summary_policy：显式启用的联合摘要/L0/L1 和上层紧凑输入；默认 full 输入、分开标注。
- detailed_summary：完整子记录分批、带来源 ID 的详细陈述、实体和导航视图；不截断下层详细摘要。
- time_hierarchy_pipeline：逐层完成摘要，再将父节点输入上层分组。
- incremental_pipeline：相邻单层分组、静默封口、安全前缀与下层待定边界。
- profile_config：不可变构建 profile 的配置解析。
- default_composer：候选树校验、持久化与区间替换，不负责候选扫描。
- recursive_composer / recursive_summary：可选会话内递归聚合、模型 Token 上限、稳定分组复用；
  复用 default_composer 的 IndexBuilder 持久化协议，不广告固定相邻层后台 profile。

## 行为铁律

- 输入先复制，叶正文、来源、时间和生命周期保持，仅变更结构引用。
- 完整事实由子事实向上传递，不能从摘要反推；结构摘录限额不截断事实或模型输入。
  显式 compact 策略只限制上层模型可见的摘要/原文锚点，不修改 TreeFact 或 Snapshot
  的完整输入。锚点整句选择，省略与缺失事实缓存必须区分；序号引用对应子节点的
  完整 TreeFact 列表。紧凑 JSON 不小于原输入时用原输入，真实 Token 仍需独立计量。
- 联合 L0/L1 通过类型与长度校验后才跳过该父的后续标注；失败保留有效摘要并走原标注器。
  全量和单层增量使用相同策略，旧子节点不重写。
- detailed 路径的覆盖 ID 校验不等于事实完整性证明；失败批显式标记，不能静默接受部分正文。
  上层逐条消费已覆盖的下层陈述，详细模式忽略 compact 的字符截断；实体只采纳输入中存在的字符串。
- 原始输入和候选树验证通过后才持久化。新父、叶父边、旧父归档和索引按既定顺序写入。
- 所有写入经 IndexBuilder；部分失败返回真实完成项和 repair_required，不宣称回滚。
- 内部增量传入准入回调时，准备结束及每批持久化前必须调用；只执行外部裁决，
  不读取身份或自行实现权限。准备拒绝不写入，写入期间拒绝保留部分结果与修复要求。
- 增量准备段只构造副本、分组及验证，无写入失败通过 HierarchyPreparationError 传递；
  _persist 必须位于准备异常转换边界之外，不能把部分写入标记为可安全重试。
- default 只支持 TIME 父链前缀；recursive 使用重复 time_span 角色与独立高度。
  两者显式重建都须备齐完整旧子树，禁止局部截断后提交。
- recursive 源排序不依赖候选枚举顺序；同时间戳先按摄入时间和来源，再按原生有效
  `_part/_parts` 分片序号及 ID 消歧。不能让存储列表的随机 ID 顺序打乱原生长消息，
  不从 user_metadata 推断序号，也不为排序改写原文或时间。
- recursive 父节点不继承 TreeFact 原文副本；只沿直接引用保留证据。所有根和中间合并
  受相同输入/输出 Token 与子数约束；输出过密可二分当前组递归构建，重复请求按
  原输入指纹复用完整分拆子树。两个摘要仍超限、不收敛或其他摘要失败须在持久化前拒绝。
  全摘要输入的既有修复轮次应明确共享总预算及每个子节点的篇幅目标；首次有效输出
  不增加提示或调用，修复提示本身计入输入上限和复用策略指纹，不额外增加重试。
  一次修复后 JSON 仍结束在字符串或结构内部时，也允许按相同规则缩小当前组合；
  普通语法错误不能触发分拆，不推测 LLM 文本接口未返回的 finish_reason。
  单源过密输出可临时按字符无损分片，携带相同来源时间/说话人并递归合并视图；
  额外分片深度由 max_source_refinements 限界，小于 128 字符的片段不再为输出失败细分。
  分片不写回 Snapshot；这一恢复次数约束不是会话树的层数上限。

## 与其他子目录的边界

控制层提供授权范围内的完整输入并调度；Evolver 只委托 Composer；公共类型负责
纯结构校验，IndexBuilder 交付本体和检索索引。这里不读取策略开关、不实现权限、
后台扫描、树查询或自动修复；静默封口是传入时刻驱动的纯构建规则。

详细摘要只对遗漏输入 ID 定向补写一次，并记录 repair_batches；补写失败仍为 incomplete，
不能循环重试或把部分生成结果声明为完整。模型端所有调用均计入构建 Token。

递归摘要使用输入编号作为必需字段，并通过既有 LLM.chat 的 JSON Schema 参数限制
实体列表长度；解析后仍校验全部字段和实际 Token。模型调用与一次修复均须计量，
不得把结构化解码当作事实正确性检查。

`recursive_event_repair.py` 解析截断事件数组中的完整条目，并为可选补齐流程生成单字段请求；最终结果由递归摘要校验。

`semantic_summary.py` 提供 structured_features 的联合标注和上层有界继承。没有事件
日期时保留 unknown，不把会话头日期当作事件日期；错误可选标注弃用并记诊断，
不能以修复为由不断重跑主体摘要。子级已解析时间向上复制，原始 Snapshot 不受影响。
原文的时间输出格式只允许带来源的区间；混合输入的继承引用必须属于指定子节点。
复用指纹包含实际提示词，修改提示词后不能继续复用旧摘要。
可选 validate_explicit_time_precision 校验已解析的来源时钟与表达精度；确定矛盾或
过细精度只降级时间字段，不改变场景、实体、状态或支持来源，并保留降级计数。
可选 repair_source_day 修复已拒绝且有确定原文日期的单日标注。保留本次合并已选
事件和实体，只替换来源一致、含义唯一的未知时间。必要时使用紧凑 JSON 并记录父
层读取所用的格式，内部标记不进入提示。关闭时保持原策略指纹。
原生 Snapshot 的有界 `user_metadata.speaker` 作为摘要归属信息传入；正文已有相同
说话人前缀时不重复，父节点不继承单一说话人。该字段参与输入指纹及实体落地校验，
不作为事件日期的原文证据；不得从 Scope 猜测说话人或修改原文来补写归属。
可选 compact_source_records 在提示词中以共享时钟和微秒偏移表示同秒原文，逐字段
还原相等后才采用；分组、语义验证和持久化仍使用原记录，预算按实际传出的表示计算。
compact_parent_records 只在全摘要输入且语义可继承时，从模型输入去掉重复 features；
完整子摘要正文保留。原始记录仍参与时间/实体继承和验证，不能从精简后的模型输入反推。

可选 compact_json_output 只提示输出省略 JSON 字符串之外的空白，不能删字段、事实或
元数据；字符串内部空白保留，合法的带缩进 JSON 仍接受。关闭时保留旧请求及策略
指纹；开启时实际提示词进入指纹及输入预算。输出上限、一次修复和解析校验不变，
不能把已有响应重新序列化后的 Token 差值当作原生生成节省。

可选 structured_output_headroom 依赖 structured_features；原文/混合输入的首轮
结构化响应可使用配置的完整 max_output_tokens，父摘要继承仍用既有派生上限。
它不放宽解析后的视图预算、输入分组或修复次数；开启后改变复用身份，关闭保留
旧请求和身份。避免截断是否节省实际费用，必须由包含失败与修复的原生计量验证。

可选 fact_first_records 要求 structured_features；原文/混合输入的同次响应逐条区分
参与者事实和讨论内容，解析为既有子摘要正文与来源区间。两项不能同时为空；格式覆盖
不代表事实无损。存在参与者事实时保留模型生成的有界 L1，不以通用讨论事件覆盖它。
全摘要输入仍沿用原有合并和特征继承；所有视图继续共用总预算，无额外抽取调用。
提示要求 content 不重复 personal，任一字段允许为空；这些是生成约束，不能将
字段非空或格式通过解释为已验证无重复或语义无损。
关闭选项须保持旧策略指纹和请求；开启后的真实提示词必须参与复用身份。
两项为空的输出不能作为来源覆盖；校验收集实际空记录的编号，仅在既有一次修复中
对这些记录的 content 追加非空约束，并要求
对空消息/应答语描述有限内容而不虚构个人事实。首次请求不变；修复提示进入策略
身份和输入上限，修复失败仍拒绝持久化，不能增加重试次数或丢掉该来源。

recursive_summary 保留本次已生成的逐输入 details；recursive_composer 只将它们编码为
正文字符区间并与有序子引用绑定，不另调模型、不复制正文或改变上层输入。临时单源
细分归并后的所有摘要片段重新归属唯一原始子节点。旧复用父无映射时保持原节点，
不能猜测逐行来源或触发全局重建；有效新映射随本体经 IndexBuilder 一起持久化。
