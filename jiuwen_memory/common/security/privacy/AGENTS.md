# 记忆隐私保护

**规约文档**：[S10 安全横切契约](../../../../docs/specs/S10-security.md)；
配置见 [S08](../../../../docs/specs/S08-config.md#隐私配置)。

## 模块地图

- `base.py`：PrivacyProtection 契约、PrivacyProducer、总开关、共享装配及原子占位符切分工具。
- `privacy_impl/regex.py`：可配置分级/正则、内存密文暂存、隔离 SQLite 片段与关联清单。
- `disclosure.py`：人类终端查看服务，绑定人机认证、正常资源判权、审计及入站预算。

## 行为铁律

- 普通处理和召回只使用脱敏记忆；敏感片段解密只发生在人类查看服务完成认证和判权之后。
- 构建和路由可以认证关联清单，但不能解密敏感片段。路由先校验候选目标，再迁移密文引用。
- 摄入阶段只做有界内存密文暂存；持久化关联绑定完整 Scope、记忆 ID、版本和内容指纹。
- 正则匹配受单次保护调用的时间预算约束；超时拒绝处理。暂存作用域在失败或完整操作结束后
  清理新项，结束后的回调不得重新暂存；独立摄入成功输出可在 TTL/容量内保留至持久化。
- 匹配预算和暂存作用域由提供者实例管理，不通过外部装饰器直接访问受保护成员；
  等级配置在构造时分项校验，布尔值不能作为等级序号、保留秒数或匹配超时。
- 客户端不得自述等级、修订号或有效占位符。未知、过期或无来源的占位符拒绝写入。
- 摄入/内容分批不拆断占位符，不扩大长度上限；判定截断完整省略跨界引用，不解密片段。
- `allow` 是直接写入豁免；原文仅供人类查看的保证适用于 `redact` 路径。
- 私有片段库不注册为 KV/DomainStore/检索端口，错误和审计不得包含正文、登记码或证明。
- SQLite 的 fragments/manifests/bindings 分别维护片段、认证快照和引用；控制元数据可见，
  不把逻辑删除描述为介质擦除，不把快照修订号描述为策略版本。
- recovery_manifests/recovery_bindings 保留委托结果未确认的密文快照及引用；write 按真源
  回读恢复存续版本，无法回读时保留候选，成功写入或硬删再回收，不作为普通历史开放。
- prepare 保护并校验引用而不发布清单；refresh_revision 只同步匹配的已提交版本。
  discard 可先执行真源删除回调，与 write 共享实例内互斥边界；删除失败不撤销关联。

## 与其他子目录的边界

接入、构建和存储通过契约调用保护；API 持有唯一资源 PEP。人机证明由
`human_authentication` 产生，本模块不复制授权规则、不把原文回写到业务流程。
