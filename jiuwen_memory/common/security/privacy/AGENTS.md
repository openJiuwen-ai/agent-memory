# 记忆隐私保护

**规约文档**：[S10 安全横切契约](../../../../docs/specs/S10-security.md)；
配置见 [S08](../../../../docs/specs/S08-config.md#隐私配置)。

## 模块地图

- `base.py`：PrivacyProtection 契约、PrivacyProducer、人类查看返回类型及 Engine 安全能力协议。
- `snapshots.py`：有界、短期、一次消费的服务端脱敏快照，不保存还原正文。
- `privacy_impl/`：同事业务的规则目录、StaticPrivacyClassifier、SensitiveTaxonomy /
  DictPrivacyManager 与 regex 适配；细节见其 AGENTS.md。策略层经 PrivacyStore 维护私有状态。
- `disclosure.py`：人类终端查看服务，绑定人机认证、正常资源判权、审计及入站预算。

## 行为铁律

- 可信规约、分类、抽取、摘要和去重可使用本次原文；持久化正文、索引及普通召回使用脱敏记忆。
  存储片段的解密只发生在人类查看服务完成认证和判权之后，不为历史处理自动解密。
- 查看 begin 经常规认证和 get PEP 取得快照，暂存后绑定挑战；finish 使用人的身份复查
  权限、ACTIVE 和版本，再经 Engine 专用返回能力消费首次快照。普通 get/search 不还原。
- 查看操作绑定浏览器、服务端目标和初次请求身份；失败/过期/完成不可重用。快照总量与
  字节数有界，仅在本 Runtime 进程内，跨实例或重启时要求重新认证。
- 构建和路由可以认证关联清单，但不能解密敏感片段。路由先校验候选目标，再迁移密文引用。
- 摄入只校验和分级，不替换原文；片段密文在落盘保护边界有界暂存，关联绑定完整
  Scope、记忆 ID、版本和内容指纹。split_input 保留已识别的原文敏感跨度，超限拒绝。
- 正则匹配受单次保护调用的时间预算约束；超时拒绝处理。暂存作用域在失败或完整操作结束后
  清理新项，结束后的回调不得重新暂存；显式 prepare 输出可在 TTL/容量内保留至持久化。
- 匹配预算和暂存作用域由提供者实例管理，不通过外部装饰器直接访问受保护成员；
  等级配置在构造时分项校验，布尔值不能作为等级序号、保留秒数或匹配超时。
- 客户端不得自述等级、修订号、privacy_rule_ids / privacy_categories 或有效占位符。
  规则名和类别仅为服务端生成的有限诊断摘要，不含匹配原值，不作为授权依据。
  未知、过期或无来源的占位符拒绝写入。
- 摄入/内容分批不拆断占位符，不扩大长度上限；判定截断完整省略跨界引用，不解密片段。
- `allow` 是直接写入豁免；`redact` 保护持久化与普通召回，不隔离可信处理中的本次原文。
- 私有片段库依赖受保护的 PrivacyStore，不直接调用密码学或 SQL；不注册为普通
  KV/DomainStore/检索端口，错误和审计不得包含正文、登记码或证明。
- storage 的 KVPrivacyStore 经独立 KV 后端原子维护片段、清单和恢复引用，
  SQLitePrivacyStore 保留旧专用表兼容；
  EncryptedPrivacyStore 负责透明加解密；暂存及路由使用不透明密文引用，不读取片段原值。
  控制元数据可见，
  不把逻辑删除描述为介质擦除，不把快照修订号描述为策略版本。
- recovery_manifests/recovery_bindings 保留委托结果未确认的密文快照及引用；write 按真源
  回读恢复存续版本，无法回读时保留候选，成功写入或硬删再回收，不作为普通历史开放。
- prepare 保护并校验引用而不发布清单；refresh_revision 只同步匹配的已提交版本。
  discard 可先执行真源删除回调，与 write 共享实例内互斥边界；删除失败不撤销关联。

## 与其他子目录的边界

接入、构建和存储通过契约调用保护；API 持有唯一资源 PEP。人机证明由
`human_authentication` 产生，本模块不复制授权规则、不把原文回写到业务流程。
