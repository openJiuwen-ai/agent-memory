页面数据从哪里来

当前页面使用真实接口数据，不含示例记忆

页面使用同源 /v1/ 接口。服务端从浏览器会话识别用户；详情、纠正和遗忘携带记录的 Scope 和 ID，用于定位并重新检查权限。

页面区域接口字段与原始含义
记忆概览POST /v1/list一次读取 lifecycle_counts，汇总全部、有效、纠正历史、已遗忘和已归档数量；应用数来自非空 sources；速览来自有效记忆的前 5 条，不代表访问热度。
复制 / 导出 / 批量遗忘/v1/get、/v1/delete只处理本页所选记录；复制和导出前重新读取详情，导出 JSON 不含页面内部记录标识。遗忘逐条调用接口并报告部分失败。
记忆列表与筛选POST /v1/listitems / count / snapshot；筛选后计数、再分页；sources / agents / projects / memory_classes 来自完整授权集合。
来源应用/v1/list、/v1/getsource ← system_metadata.source_app；缺失显示“未标注来源”。
Agent / 项目/v1/list、/v1/getagent ← scope.agent；agent_label 是显示名称。project ← 文档记忆的 system_metadata.project（直传）或 coords.project（router 回写），空值显示“跨项目 / 未标注”。
内容快捷筛选POST /v1/list用户画像：memory_class=user_profile；项目知识：memory_class=long_term_memory + tier=semantic；过程与做法：tier=procedural。保留其他筛选，不新增分类或自动识别。
层级 / 记忆分类/v1/list、/v1/gettier ← MemoryTier.value；筛选项对应六个认知层级。memory_class ← system_metadata.memory_class；memory_classes 来自授权集合，支持自定义分类。层级 archival 与生命周期 archived 是不同维度。
完整详情与时间POST /v1/get每次重读 segments / lifecycle / tags / source_ref / supersedes / temporal.t_ingest；时间来自 temporal.t_ingest，不是文件修改时间。
新增 / 纠正 / 遗忘/v1/add、/v1/update、/v1/delete新增提交正文、Agent 和可选项目；宿主可绑定实际 Agent 范围。纠正与遗忘通过 scope 和 unit_id 定位，服务端再次检查归属和权限。纠正创建 SUPERSEDE 新版；遗忘使用 FORGET。
检索结果POST /v1/searchitems / scores_comparable；来源先筛选再 top_k。按记忆范围轮转合并。
模型配置与应用/v1/read_config、/v1/save_configfields / version / applied_version / apply_state / instance；API Key 不回填，只显示已配置状态。

来源标签用于展示和筛选，不承担授权。未标注来源不会被猜成当前应用。
