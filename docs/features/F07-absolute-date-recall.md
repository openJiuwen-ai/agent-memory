# F07 — 绝对日期两侧共享规则：查询时间窗与写入事件时间（issue #252）

|---|---|

| 影响范围 | `jiuwen_memory/common/time_utils.py`（`first_absolute_date` + 两形态正则）、`jiuwen_memory/retrieval/query_parser_impl/time_parse.py`（查询侧回退）、`jiuwen_memory/ingest/ingestor_impl/simple_ingestor.py`（写入侧 `t_event`） |
| 测试基线 | TDD 新增用例全绿；全量 unit 失败集合与干净 HEAD 基线一致（既有测试隔离 flakiness，零新增） |

## 背景

时间语义此前只覆盖相对时间词（"昨天"/"上周"），绝对日期字符串
（"2026年6月8日"、"6月8日"）两侧都不解析：

- 查询侧：`time_parse` 解析不出时间窗 → 日期查询退化为全量检索或空召回；
- 写入侧：`SimpleIngestor` 直存链路 `t_event=None`（哨兵），时间窗谓词对
  该 unit 恒放行 → 日期过滤被静默架空。

修复为两侧对称补齐，且**必须共用同一份规则**——查询侧把日期解析成时间窗、
写入侧把同一日期字符串解析成 `t_event`，两侧规则哪怕只差一个解释（形态、
时区、取首口径），时间窗就命中不了对应 unit。这是跨模块不变量，归档于此。

## 方案：common/time_utils.first_absolute_date

```
带年形态  (?<!\d)(\d{4})[-/年][的，,\s]*(\d{1,2})[-/月][的，,\s]*(\d{1,2})(?:[日号])?(?!\d)
无年形态  (?<![\d年])(\d{1,2})月(\d{1,2})[日号]
```

- 两侧调用：查询侧 `time_parse`（相对规则解析不出时回退本函数生成当日窗）、
  写入侧 `SimpleIngestor.ingest`（`t_event=first_absolute_date(content, now)`）。
- 匹配按文本位置排序取首个；同位时分组多者（带年）优先（仅稳定排序用）。
- 带年用显式年份；无年按 `now.year` 补齐，时区取 `now` 的时区，返回当日零点。
- 非法日期（6月32日、13月）跳过并尝试后续匹配；全部不可解析返回 `None`。

## 关键取舍

- **位置优先，而非形态优先**：多日期文本「6月6日团建，2026年6月8日吃饭」
  取 6月6日——"第一个绝对日期"按阅读顺序理解，与"先找带年再找无年"的
  形态优先口径冲突时，选位置（用户的"第一个"指位置）。同位 tie-break 取
  分组多者，仅为排序稳定，两形态起始位置本就不重叠。
- **无年形态前置断言排除 `[\d年]`**：不吃相邻数字（「编号12026年6月8日」
  的「12026年6月8日」整体不匹配）；更重要的是不把「2026年13月1日」这类
  非法带年日期截成「13月1日」重新解释为无年命中——带年解析失败的输入
  不能换一种形态"救活"成错年结果。
- **无年形态尾部不断言数字**：「6月8日14点」的日期提取不受后接时间数字
  影响；带年形态经正则回溯本就能命中后接数字的场景，两形态行为一致。
- **带年形态容忍「的」/逗号/空白**（「2026年的6月8日」）：否则显式年份
  掉进无年形态、被 `now.year` 静默顶替成错年——显式年必须优先于推定年。
- **跨年解释**：无年日期按调用当时的 `now.year` 补齐。同一自然年内写入与
  查询解析到同一天；跨年指代（1 月说「去年6月」）属相对时间词，归查询侧
  相对规则，本函数不处理。代价：去年 12 月写的「6月8日」今年查会解释成
  今年 6 月 8 日——两侧一致地错，好过两侧不一致。
- **多日期 / 区间只记首个**：直存链路每个 unit 只有一个 `t_event`。
  「6月20日到21日」取首日；多日期内容其余日期不进 `t_event`——拆分归
  EXTRACT 链路（一事实一 unit），跨度建模归时间树结构，此处不展开。

## 跨模块约束（改代码前必读）

1. **两侧只能共用 `common/time_utils` 这一份规则**：查询侧 `time_parse`
   与写入侧 `SimpleIngestor` 都不得内联自己的日期正则。调整形态、口径、
   取首规则时只改 `time_utils` 一处，两侧测试同时覆盖。
2. **!351（大文本预切分）合并联动**：`SimpleIngestor` 预切分后每片继承
   同一 `t_event`——`first_absolute_date` 必须在切分**之前对全文**计算，
   不允许对分片各算（后片的日期会丢）。两 PR 谁后合并谁在 rebase 时补
   该行。
3. 无年日期依赖调用方传入有意义的 `now`（查询侧=当前时间，写入侧=ingest
   时刻）；`now.tzinfo` 为空时按 UTC 解释，与 `as_utc` 口径一致。
