## 背景

F12 的上游集成基线未覆盖撤权 ID 与真实资源绑定、治理读取逐条隔离、SQLite 更新和
集合编码，以及全部公开入口的前置可信性检查。后续独立验收列出 R1–R9；本轮复现后
修复这些边界，不改变已冻结公共接口，不提前实现 PR3。

## 决策

1. 撤权先从服务端真源读取 ID 对应的 grantor，再执行 REVOKE_SHARE，最后原子校验
   grantor 未变化才撤销。使用实现私有查找/条件更新接缝，保留公共 Store 契约；缺接缝的
   第三方 Store 对该操作失闭。未知 ID 幂等，重复撤销不刷新 SQLite 撤销时间。
2. inspect/trace 对每个返回快照（包括祖先）的 Scope、作者、memory_type/pipeline
   重新判定 READ；不另读一份权限上下文，避免验证对象与返回内容错位。
3. 两种 Store 对同 ID 活动记录统一全字段更新，包括身份范围、凭据/会话绑定及 revoked。
   已撤销记录不再接受更新；内存后端复制 Scope，避免可变对象别名绕过锁内目标检查。
4. SQLite allowed_spaces 改为 JSON，并增加 encoding 标记，不能靠内容外观猜格式。
   旧空串和无逗号单值保持兼容；旧含逗号行存在单空间/多空间歧义，读取抛 BackendError，
   由可信部署按明确原始集合重新写入。损坏 JSON、未知版本不得变成空集合。
5. 授予上界接收可信上下文，只为 ROOT 免除普通成员上界；ADMIN 仍不自动获得内容权，
   普通成员自提禁止保留。业务读取前完成上下文来源、完整性、时效、凭据撤销复核。
6. 所有受控上下文构造复用既有 actor 校验。旧测试中缺 org、无主体或双主体 actor 改为
   合法具名身份；真正的代理测试创建真实委托记录，不把认证 actor 偷换为资源 Scope。
7. 路由写入传播 BackendError；跨空间查询单列授权后端故障，全部候选因后端故障失败时
   返回 BackendError，部分成功时保留独立错误明细，不折算为普通权限拒绝。
8. 恢复 F04 原归档并明确历史状态，更新 S10 与模块说明。F12 保留历史验证数据，但不再
   声称独立验收后仍无阻断项。
9. 后续代码门禁整改保持判权语义不变：把委托复核拆成按主体、时效、绑定和目标收窄的
   独立检查；PEP 预检用私有目标值对象携带动作和审计信息，不改变公共方法签名。
   旧 SecurityContext 兼容构造调用父类初始化，保留位置参数顺序、默认值和 metadata 复制。
10. 门禁报告 67 条中，24 条通过修改消除；其余 43 条为必要私有访问（5 条装配、38 条
    白盒测试）。装配同源绑定和故障注入仅局部声明 protected-access 例外，不全局关闭
    检查，不增加公共调试接口，不删测试。另为前轮新增的 Store 白盒回归补同类局部说明。
    permission 装配守卫直接接收已构造对象，不再读取 API 私有成员。
11. 后续 18 条门禁补充中，16 条属于独立验收测试和委托夹具的必要私有访问，按具体
    函数补理由与局部声明；所有入口矩阵用 get + 唯一缺失哨兵读取测试参数，漏配必须
    明确失败，不能以 None 代填。MCP submit_ingest 保留五个业务参数和框架注入 ctx，
    仅对该定义声明标准及华为参数数量规则例外，避免把扁平工具协议改为嵌套参数袋。

## 拒绝的方案

- 只比较请求 grantor 或把随机 ID 当权限凭据：不能绑定真实被撤销对象。
- 扩展冻结 GrantStore 公共接口、恢复旧 PermissionManager：本轮无需改契约或引入第二真源。
- 治理读取只做 Scope 判权或使用第二次查询的权限快照：作者/类型旁路或快照错位仍存在。
- SQLite 仅修绑定字段，或无条件覆盖撤销状态：分别遗漏其他限制更新或允许重放复活。
- 猜测旧逗号串含义、把解码失败当无限制：可能扩大委托权。
- 放宽 SDK actor 形态来迁就旧测试：违反全局单主体约束，无法证明真实代理链路。
- 后端不可用返回 False 或 403：掩盖依赖故障，改变落点和召回错误语义。
- 为静态门禁新增公共 Runtime/PEP 方法、用 getattr 隐藏静态可见的私有访问，或删除
  真源一致性/故障注入测试：分别破坏冻结边界、掩盖依赖或降低安全回归强度。

## 已知遗留

第三方 GrantStore 若要支持公共 revoke，须实现本轮私有安全接缝，不能退回无目标绑定撤权。
旧 SQLite 含逗号空间限制必须由运维依据原配置重新写入；数据库不会自动猜测授权范围。
动态委托管理公开接口、审计完整性实现和 FS 加密均不属于本轮。
专有门禁平台尚未重扫；43 条私有访问是否接受局部声明，以平台实际结果为准。若平台不
接受 Pylint 行/函数级声明，应按门禁流程复核例外，而不是放宽接口或安全检查。

单处声明，另 1 条字典索引改为显式失闭检查；这些新增声明的最终认可同样以平台为准。
